# An — Flutter Brand + Cultural Stories v1.0

**Sản phẩm:** An (một chữ). Logo chuẩn: hoa sen xanh từ v0.8. Tông màu xanh teal đậm–kem đồng nhất. Đây là bản tích hợp v0.8 media với lớp lịch sử/văn hóa và nhận diện mới.

- `packages/an_brand`: Widget Flutter hiển thị logo duy nhất.
- `assets/branding/an`: master PNG/lockup/logo, video watermark, bumper intro/outro.
- `branding/platform`: Android/iOS icon hoàn chỉnh.
- `scripts/apply_an_branding.py`: script đổi launcher display name thành `An` trên **codebase Flutter thật** (có backup; mặc định dry-run).
- `packages/an_nhien_cultural_content`: 67 giải thích động tác, 7 hồ sơ và 6 chuyện kể; package ID giữ nguyên để không phá import.
- `docs/BRAND_AN.md`, `docs/CULTURE_INTEGRATION.md`: quy tắc/triển khai.
- Catalog/media v0.8 giữ nguyên trừ badge chuẩn trên các ảnh bìa; không làm giả video đã duyệt.

**Không phải** bộ video/voice final hay nội dung được chuyên gia duyệt. Xem `docs/RELEASE_LIMITATIONS.md`.
